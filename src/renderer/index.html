      Create a Google Cloud project, enable YouTube Data API v3, configure an External OAuth consent screen, add yourself as a test user, then create a Desktop app OAuth client.

      The Client ID and Client Secret let the app ask Google for permission to list your YouTube playlists. Only use them if you want to choose playlists from your YouTube account; manual YouTube URLs and YouTube Premium playback sign-in do not require them.
